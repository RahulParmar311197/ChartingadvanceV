# TradingView Clone

A frontend starter for a TradingView-style charting workspace.

## Stack

- React 19
- Vite
- Lightweight Charts
- Lucide React

## Run

```bash
npm install
npm run dev
```

## Included

- Dark charting workspace
- Symbol search
- Watchlist with symbol switching/removal
- Interactive timeframes
- Candlestick and volume chart
- Drawing toolbar shell
- News panel
- Bottom workbench/trading tabs
- Responsive layout
