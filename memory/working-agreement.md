# Working Agreement

## Continuity rule
No session is isolated. Durable context belongs in repository memory, not in an agent's private assumptions.

## Every meaningful task records
- objective
- current state
- files/modules changed
- decisions
- tests run
- known limitations
- next recommended action

## Conflict rule
If documentation and implementation disagree, record the discrepancy in `docs/PROJECT_STATE.md` and resolve it deliberately. Never hide the mismatch.

## Agent handoff
Before handing off work, update `memory/active-work.md` and `AGENT_HANDOFF.md` with exact status and next steps.
